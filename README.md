# Макеты Базис

Демонстрационный макет главной страницы платформы для заказа кухонь и шкафов.

**Просмотр:** https://erlsky.github.io/bazis-design-demo/demo/

Страница находится в `demo/index.html`. Публикация: GitHub Pages, ветка `main`, папка `/ (root)`.
Сборка и установка зависимостей не нужны.

Конструктор обозначен статичным изображением: реальная интеграция пока не подключена.
Карточки специалистов, оценки и отзывы вымышлены для демонстрации интерфейса.
Форма обращения не отправляет и не сохраняет введённые данные.
Изображения и иконки включены в страницу; шрифт Manrope загружается из Google Fonts.

Для обновления макета замените `demo/index.html` и отправьте изменения в `main`.
